¿Por qué existe detalle_pedidos?

Un pedido puede incluir varios productos y cada producto puede estar en muchos pedidos. La tabla de detalle resuelve esa relación y almacena cantidad, precio unitario y subtotal de cada línea.

Regla de integridad

Si un cliente no existe o falta inventario, la API responde con error. La transacción hace ROLLBACK para evitar pedidos parciales o descuentos de stock incompletos.
